ปุ่มลัดด้านล่างแชท (quick reply) ใช้แทนการพิมพ์ในข้อ 2, 3, 6, 7, 8 ได้

## สิ่งที่แต่ละข้อแสดง (ไว้เขียนใน README)
- ข้อ 2, 3, 6, 7: ตอบผ่าน reply message ซึ่งฟรี ไม่กินโควตา push
- ข้อ 4, 5: เตือนก่อนปิดรับ 3 วันและ 1 วัน ตั้งได้ทั้งในแชทและจากเว็บ
- ข้อ 8, 9: ผู้ใช้เลือกเองว่าจะติดตามกลุ่มไหน (นักศึกษา / ครู)
- ข้อ 10: push ส่งวันละไม่เกิน 1 ข้อความต่อคน และอยู่ในโควตาฟรี 300 ข้อความต่อเดือน
- ข้อ 11: บัญชีเว็บกับแชท LINE เป็นคนเดียวกัน
- ข้อ 13: ผู้ใช้ลบข้อมูลตัวเองได้ทันที
